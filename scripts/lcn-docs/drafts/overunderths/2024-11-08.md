This release wired OverUnderTHS deeper into Firebase and added a **daily reward** loop on the main client.

Navigation across leaders, map, stocks, and related pages was tightened so signed-in players could move through the beta without as much breakage. Leaderboard reads and client data paths started depending more on live Firebase config instead of one-off local state.

It was an infrastructure-heavy day: rewards, auth-backed screens, and the scaffolding that later versions (2.0 / 2.5) built on.
